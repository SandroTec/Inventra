# Product Requirements Document (PRD)

## Purpose

Inventra is a web application for managing physical assets and inventory.

It is designed primarily for small and medium-sized businesses that currently rely on spreadsheets or manual processes.

---

# Target Audience

Primary users:

- Small businesses
- IT departments
- Agencies
- Workshops
- Schools
- Offices

---

# Problem Statement

Many businesses struggle with:

- Lost equipment
- Missing documentation
- Unknown asset locations
- Expired warranties
- Manual inventory tracking
- Lack of transparency

Inventra aims to solve these problems.

# Out of Scope

The following features are intentionally excluded from the MVP:

- QR Codes
- Barcode Scanner
- PDF Export
- Email Notifications
- Mobile App
- Multi Tenant
- AI Features

These may become future releases.

---

# Goals

The MVP should demonstrate:

- modern frontend development
- scalable architecture
- maintainable code
- clean UI
- responsive design
